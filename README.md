# Data Governance Lab

Practice the judgment involved in data governance consulting. Interview fictional stakeholders, inspect incomplete evidence, explain a business problem, propose proportionate controls, and defend your recommendation.

**Status:** early prompt-based pilot. No server, API key, account, or paid infrastructure is required from the project owner. Players use their own AI chat access. This is formative practice, not a secure exam or professional credential.

## Play the first case

Start with [Case 01: Three numbers in the executive pack](cases/01-two-numbers/PLAY.md). A facilitator copies the [complete case prompt](cases/01-two-numbers/FACILITATOR.md) into a fresh AI conversation, then the learner says "Start Case 01." A solo learner can paste it too, but can see the answer key in the source. The case is fictional and takes roughly 35–50 minutes.

Pilot facilitators and testers can use the [checklist](cases/01-two-numbers/pilot-checklist.md). Please report factual contradictions, premature reveals, inaccessible evidence, and feedback unsupported by the learner's work.

The prototype separates fixed case facts from the AI's performance. AI may phrase stakeholder dialogue naturally, but it must not invent a new cause, amount, or document. The public repository contains the answer key, so players can spoil the mystery by reading the facilitator file.

## Direction

First validate one case, then add an authored second case and reusable case schema. After that, allow a learner to select difficulty and industry and have AI generate a case once at kickoff. A skills-only plugin may package the same material without a project-hosted MCP server; its instructions alone cannot guarantee secrecy or deterministic scoring.

This project is an educational simulation. Its company, people, figures, and internal policies are fictional.
